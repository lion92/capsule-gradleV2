== Décisions techniques

1. `open class` au lieu de `abstract class` pour la task Gradle — résout le problème de décoration Gradle (abstract task + TestKit)
2. `ChapterEntryParser` extrait en objet pur séparé — testable sans Gradle, parsing JSON robuste avec regex `}\\s*,\\s*\\{`
3. Card HTML inline CSS 1920×1080 — pas de fichier CSS externe, template autonome pour Playwright capture
4. Pas de `dependsOn("generateCapsuleContent")` — chapters indépendant du pipeline LLM
5. Factory 9e/10e inline dans la task (pas CapsuleManager) — évite la dépendance statique
