== Mission

Cadrage formel de l'EPIC CAP-PODCAST — extraction audio-only (mode podcast).
L'objectif MVP0 est de servir les stagiaires en mobilité : le MP3 existe déjà
par slide (`build/capsule/<deckName>/slide-XX.mp3`), il suffit de concaténer
pour produire un fichier unique `${deckName}.mp3` consommable sur lecteur
audio. Pas de nouveau moteur TTS, pas de nouvelle capture — réutilisation
pure des artefacts existants via FFmpeg concat.

== Audit code (15 constats)

. **MP3 slides déjà produits** par `CapsuleBuildTask.kt:125` + `CapsuleVideoTask.kt:390` :
  `deckOutputDir.resolve("slide-$idx.mp3")` où `idx = String.format("%02d", seg.index)`.
  Localisation : `build/capsule/<deckName>/slide-01.mp3`, `slide-02.mp3`, ... `slide-NN.mp3`
  (zero-padded 2 digits). Le `deckName` est parsé depuis `*-script.txt` via
  `CapsuleScriptReader.read(script)`.

== Décisions architecturales (12)

. **Domaine `capsule.podcast` (13ème)** — nouveau domaine DDD pur (data class config + object pur
  concatenator + interface/Impl/NoOp + tâche Gradle). Fichiers prod dans
  `src/main/kotlin/capsule/podcast/`. Pattern `capsule.audio`/`capsule.transcript`/`capsule.validation`.
  13ème domaine après feed/pipeline/ai/context/multilang/validation/audio/i18n/ci/transcript/remotion +
  support.

. **`PodcastConfig` 13ème section `CapsuleConfig`** — 2 champs `enabled: Boolean = false` (opt-in,
  backward compat — configs existantes sans `podcast.enabled` ne produisent pas de MP3) +
  `outputFile: String = ""` (défaut vide → convention résout `build/capsule/<deckName>-podcast.mp3`).
  Pattern `TranscriptConfig` (2 champs, defaults backward compat). Pas de `outputDir` (la sortie
  vit dans `build/capsule/` déjà résolu par `CapsuleExtension.outputDir`).

. **4 sources DSL** — ENV `CAPSULE_PODCAST_ENABLED` + `CAPSULE_PODCAST_OUTPUT_FILE` < props
  `capsule.podcast.enabled` + `capsule.podcast.outputFile` < YAML `podcast.enabled` +
  `podcast.outputFile` < CLI `-Pcapsule.podcast.enabled` + `-Pcapsule.podcast.outputFile`.
  `mergePodcastConfig` pattern `mergeTranscriptConfig` (`mergeBoolean` enabled + `mergeStr` outputFile
  avec env fallback). `loadFromEnvironment` + `buildConfigFromProperties` étendus.

. **`PodcastConcatenator` object pur** — `buildConcatArgv(mp3Files: List<File>, outputFile: File,
  ffmpegPath: String): List<String>` utilise FFmpeg concat demuxer (`-f concat -safe 0 -i <listfile>
  -c copy <output>`) — nécessite un fichier liste temporaire `concat-list.txt` (un ligne
  `file '/abs/path/slide-01.mp3'` par slide). Alternative : pipe `concat:a.mp3|b.mp3|c.mp3` (plus
  simple, pas de fichier temp, mais limite ~1024 chars sur certains OS). **Décision : concat demuxer**
  (robuste, scalable à 32+ slides, pattern `AudioPostCommand` buildArgv pure). L'Impl gère l'écriture
  du fichier liste temporaire + cleanup (try/finally pattern `mixAudioWithVideo`).

. **`PodcastConcatenatorImpl` (FFmpeg)** — `interface PodcastConcatenator { fun concatenate(mp3Files:
  List<File>, outputFile: File): Boolean; fun isAvailable(): Boolean; fun name(): String }`.
  `concatenate` retourne `Boolean` (pattern `VideoFormatConverter`/`AudioPostProcessor` — degraded
  mode : si échec, caller garde l'état, pas de crash). `isAvailable()` check `ffmpeg -version`.
  Impl : write `concat-list.txt` → `ProcessBuilder(buildConcatArgv).start()` → waitFor → exitValue 0 =
  success. Try/finally cleanup `concat-list.txt`.

. **`NoOpPodcastConcatenator`** — `concatenate` retourne `false` (degraded, no MP3 produced, log
  warn "podcast skipped (ffmpeg unavailable or noop)"). Pattern `NoOpAudioPostProcessor`. `isAvailable()
  = true`, `name() = "noop-podcast"`.

. **Factory `resolvePodcastConcatenator` (8ème)** — `CapsuleManager` companion. `ffmpegPath = "noop"` →
  NoOp, unavailable + non-strict → NoOp, unavailable + strict → throw via `StrictModeGuard.requireAvailable
  (strict, "ffmpeg (podcast)", false, ffmpegPath)`, available → Impl. Pattern `resolveAudioPostProcessor`
  (L480-489).

. **Tâche `generateCapsulePodcast`** — groupe `generate` (réutilise `task.group.generate`), `dependsOn
  ("generateCapsuleVideo")` (les MP3 slides sont produits par `synthesizeTtsForScript` dans
  `CapsuleVideoTask`, pas par `generateCapsuleContent` qui produit les speaker notes AsciiDoc).
  `@DisableCachingByDefault(because = "Podcast concatenation (ffmpeg)")`. Inputs : `@InputFiles
  @PathSensitive(RELATIVE) audioFiles: ConfigurableFileCollection` (les `slide-*.mp3` résolus depuis
  `build/capsule/<deckName>/`) + `@Input deckName: Property<String>`. Output : `@OutputFile
  podcastOutput: RegularFileProperty` (convention `build/capsule/<deckName>-podcast.mp3`).
  Économie d'encre : skip si `podcastOutput` existe ET `MediaProbeUtil.probeDuration(podcastOutput) > 0.0`
  (pattern `FormatConversion.convertIfNeeded` L46). Si `!enabled` → no-op + log "skipped". Si
  `audioFiles` vide → warn + skip (non-bloquant — le pipeline vidéo peut ne pas avoir produit de MP3
  en NoOp TTS). Sinon factory `resolvePodcastConcatenator` + `concatenate(mp3Files, output)`.

. **`CapsuleExtension` étendu 2 properties** — `podcastEnabled: Property<Boolean>` convention `false`
  + `podcastOutputFile: Property<String>` convention `""`. `CapsuleConventions` étendu 2 champs
  (`podcastEnabled = false`, `podcastOutputFile = ""`). `pushConfigIntoExtension` podcast block
  (2 guards `isPresent` + convention, pattern transcript L203-209).

. **`CapsuleMessages` 25ème key** — `task.generateCapsulePodcast.description` ajouté à `Messages.properties`
  (base EN) + 9 `Messages_*.properties`. Groupe `task.group.generate` réutilisé (pas de nouveau
  groupe). Description EN : `Concatenates slide MP3 audio files into a single podcast MP3 (audio-only,
  for mobile learners)`. Tests `CapsuleMessagesTest` + `MessagesFrTranslationTest` étendus (gap
  connu : 3 keys non testées `verification`/`validateCapsuleVideoDuration`/`generateCapsuleTranscript`
  — backfill optionnel US-2, pas blocking — si non backfillé, la nouvelle key sera dans le même état
  que ces 3, i.e. présente dans `Messages.properties` mais absente des `@ValueSource`).

. **Cucumber runner dédié 17ème** — `CapsulePodcastCucumberRunner` (pattern S-082
  `@SelectClasspathResource("features/capsule_podcast.feature")` + `glue = ["capsule.scenarios"]` +
  `plugin = ["pretty", "html:build/reports/tests/cucumberTestPodcast.html"]`). Steps
  `CapsulePodcastSteps` préfixés "podcast" (bug S-088 — `capsule.scenarios` glue partagée, step
  phrases uniques : "the podcast deck {string} has {int} slide MP3 files" vs transcript "a transcript
  plan for deck {string}"). `CucumberTaskSpec("cucumberTestPodcast")` 17ème câblé `build.gradle.kts`
  (après `cucumberTestTranscript` L163, avant `cucumberTestIntegration`).

. **Économie d'encre (AGENT.adoc)** — skip si `podcastOutput` existe ET `probeDuration > 0.0` (re-concat
  d'un MP3 déjà valide = gaspillage). Skip si `!podcastEnabled` (défaut false, backward compat). Skip
  si `audioFiles` vide (pipeline vidéo NoOp TTS ne produit pas de MP3 — degraded, log warn). Skip si
  ffmpeg unavailable + non-strict (NoOp). Le probe `ffprobe` est cheap (< 1s) — pas de gating
  nécessaire.
