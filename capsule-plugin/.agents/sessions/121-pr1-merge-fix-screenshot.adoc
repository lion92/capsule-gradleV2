== Fix post-merge baby-step TDD/BDD

=== Constat

`ScreenshotCaptureImpl.isAvailable()` (PlaywrightManager.kt:203) ne vérifiait
que Chromium/Playwright, pas ffmpeg. Avec `ffmpegPath="noop"`,
`isAvailable()` retournait `true`, puis `capture()` crash avec
`IOException: Cannot run program "noop"`.

La PR #1 a rendu `ScreenshotCaptureImpl` fonctionnel (ffmpeg PNG→WebM réel),
mais n'a pas étendu `isAvailable()` pour vérifier ffmpeg.

=== Fix RED → GREEN

*RED* : `functionalTest` — 1 FAIL `CaptureStrategyFunctionalTest` "strictMode
succeeds" (ffmpeg "noop" inexistant → `IOException`).

*GREEN* :
. `ScreenshotCaptureImpl.isAvailable()` étendu — ajoute
  `isFfmpegAvailable()` qui probe `ffmpeg -version` via ProcessBuilder.
  Si ffmpeg inexistant → `isAvailable()` retourne `false` → `CaptureResolver`
  fallback NoOpPlaywrightCapture (non-strict) ou `StrictModeGuard` throw
  (strict).
. Test functional `CaptureStrategyFunctionalTest` scénario #3 corrigé :
  "strictMode succeeds" → "strictMode fails when ffmpeg is unavailable"
  (`assertThrows<UnexpectedBuildFailure>` + message "screenshot is not
  available").
. Cucumber `capsule_capture_strategy.feature` scénario #3 corrigé :
  "strictMode succeeds" → "strictMode fails when ffmpeg is unavailable"
  + steps `the capture strategy build fails` + `the capture strategy
  failure message contains {string}` ajoutés dans `CapsuleCaptureStrategySteps`.
  `runCaptureStrategyBuild()` étendu pour catch `UnexpectedBuildFailure` +
  stocker `buildFailure`.

*REFACTOR* : `isFfmpegAvailable()` private helper (pattern `runFfmpeg`),
temp file `deleteOnExit()`, `availabilityProbe` cache préservé.
